# Workflow

## Steps

| Step | Who |
|---|---|
| Idea | Owner |
| Discovery | `analyst` and `scout` |
| Draft epic and stories | `analyst` |
| Design | Coordinator |
| Approval | Owner |
| Build | `implementer`, `runner` |
| Acceptance | Coordinator, owner |
| Commit | Coordinator, on the owner's direction |

## Agents

| Agent | Does |
|---|---|
| Coordinator | Plans, delegates, reviews, talks to the owner |
| `analyst` | Writes epics and stories, files them in Linear |
| `scout` | Finds things in the repo |
| `docs` | Looks up library documentation |
| `researcher` | Assesses technical choices |
| `implementer` | Writes code from a spec |
| `runner` | Runs tests, lint and builds |
